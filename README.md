[Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209).

`main.py` (Python 3.13, standard library only) writes the single line an AI
agent would post about its human on a rating site to `/output/entry.txt` —
one line, at most 200 characters, in the agent's own voice, and funny.

```sh
python3 -P -s main.py
cat /output/entry.txt
```
